# 📝 React Todo App (Zustand + TypeScript)

Простой, производительный и отзывчивый менеджер задач (Todo List), разработанный на **React**, **TypeScript** и **Zustand**. Приложение демонстрирует архитектурно правильный подход к управлению глобальным состоянием без использования тяжеловесных решений и Context API. Все данные синхронизируются с `localStorage`.

---

## ✨ Основной функционал (Features)

- **Глобальный стейт через Zustand**: Быстрое, реактивное состояние без оборачивания дерева компонентов в `Provider`.
- **Persistent Storage**: Использование middleware `persist` для автоматического кэширования списка задач в `localStorage` браузера.
- **Гибкая фильтрация**: Сортировка задач по категориям «Все», «Готово» и «Не готово» без лишних запросов.
- **Управление жестами мыши**:
  - `Левый клик` — быстрое переключение статуса выполнения (completed / не completed).
  - `Правый клик` — мгновенное удаление задачи (с блокировкой дефолтного контекстного меню браузера `e.preventDefault()`).
- **Защита от некорректного ввода**: Синхронная валидация данных (проверка на пустые строки и пробелы) прямо внутри экшенов стора.

---

## 🛠️ Стек технологий (Tech Stack)

- **Библиотека интерфейса**: React (Управляемые компоненты, Hooks)
- **Управление состоянием**: Zustand + Middleware (Persist)
- **Язык программирования**: TypeScript (Строгая типизация интерфейсов стора и элементов)
- **Утилиты**: `clsx` (Для чистой и удобной условной комбинации CSS-классов)
- **Стилизация**: CSS Modules (Изолированные стили для исключения конфликтов классов)

## 🚀 Инструкция по запуску проекта (Installation & Setup)

Для запуска проекта локально вам понадобятся установленные **Node.js** (версии 18 и выше) и менеджер пакетов (`npm` или `yarn`).

### 1. Клонирование репозитория
Клонируйте этот репозиторий на свой компьютер:
```bash
git clone https://github.com
cd react-todo
```

### 2. Установка всех зависимостей
Установите необходимые пакеты (React, Zustand, TypeScript, clsx и др.):
```bash
npm install
```

### 3. Запуск в режиме разработки
Запустите локальный сервер разработки:
```bash
npm run dev
```
После запуска консоль выдаст локальную ссылку (обычно `http://localhost:5173` или `http://localhost:3000`). Откройте её в браузере.

### 4. Сборка проекта (Production Build)
Для создания оптимизированной production-сборки выполнено:
```bash
npm run build
```

## 🏗️ Архитектура хранилища

Вся логика приложения инкапсулирована в файле стора. Zustand обновляет стейт атомарно (за один вызов `set`), что исключает каскадные рендеры компонентов. Настройка `partialize` гарантирует, что в `localStorage` попадут только сами задачи, в то время как временные ошибки валидации и фильтры сбрасываются при перезагрузке страницы, оставляя интерфейс чистым.
